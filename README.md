 ## 소개

 컴퓨터과학을 기반으로 **정보보안과 정보관리**를 함께 공부하고 있는 학부생입니다.

 소프트웨어가 동작하는 원리부터 데이터가 저장되고 전달되는 과정, 그리고 이러한 시스템을 안전하게 보호하는 방법에 관심이 있습니다.

 단순히 기술을 사용하는 것보다 **문제를 정확하게 정의하고, 시스템의 구조를 이해하며, 적절한 기술을 통해 해결하는 과정**을 중요하게 생각합니다.

 현재는 컴퓨터과학의 기초를 탄탄하게 다지는 동시에 정보보안과 정보관리 분야의 지식을 실제 프로젝트에 적용하는 것을 목표로 학습하고 있습니다.

 ## Development Philosophy

 > **Understand the system. Protect the information. Build with purpose.**

 저는 개발 과정에서 단순히 동작하는 결과물을 만드는 것보다 **시스템의 구조와 문제의 원인을 이해하는 것**을 중요하게 생각합니다.

 하나의 시스템을 바라볼 때 다음과 같은 질문을 고민합니다.

```
어떻게 동작하는가?
        ↓
왜 이렇게 설계되었는가?
        ↓
어떤 문제가 발생할 수 있는가?
        ↓
어떻게 더 안전하고 효율적으로 만들 수 있는가?
        ↓
정보는 어떻게 관리되어야 하는가?
```

 궁극적으로는 **소프트웨어를 개발할 수 있는 능력과 시스템을 분석하고 보호할 수 있는 능력**을 함께 갖춘 엔지니어로 성장하는 것을 목표로 합니다.
